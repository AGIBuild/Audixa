## ADDED Requirements
### Requirement: Learning Time Summary UI
The desktop app SHALL display learning time totals for today, last 7 days, and last 30 days.

#### Scenario: View summary totals
- **WHEN** the user opens the learning stats section
- **THEN** the UI shows totals for today, last 7 days, and last 30 days

### Requirement: Learning Time By Resource
The desktop app SHALL display learning time totals grouped by media source.

#### Scenario: View per-resource totals
- **WHEN** the user views the per-resource breakdown
- **THEN** the UI shows a list of media sources with their learning time totals
