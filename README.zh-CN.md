# Audixa

> 字幕驱动的语言学习播放器

**把任何视频变成你的语言学习课堂。**

Audixa 是一款创新的音视频学习播放器，以**字幕句子**为核心，让你通过观看电影、美剧、纪录片等内容，高效提升语言能力。

## Audixa 的与众不同

不同于普通播放器，Audixa 将每一句字幕都变成可交互、可追踪的学习单元：

- **点击即跳转** — 点击任意字幕，立即定位
- **循环即复读** — 一键循环，反复精听
- **遮罩即挑战** — 隐藏字幕，考验听力
- **记录即进步** — 量化学习行为

## 核心功能

### 🎯 句子级精准控制

- 点击任意字幕句子精准跳转
- AB 循环自动识别句子边界
- 字幕遮罩/模糊听力挑战
- 双语字幕并行显示

### 📚 精听库

- 一键保存精彩句子
- 独立播放音频片段
- 打造个人听力素材库

### 📖 生词本

- 点词即查释义发音
- 一键添加到生词本
- 关联语境帮助记忆

### 📊 学习统计

- 句子播放/循环次数追踪
- 学习时长记录
- 进度可视化展示

### 🌐 全平台支持

- **桌面端**：Windows、macOS
- **移动端**：iOS、Android（即将推出）
- 本地优先数据存储

- SRT（最常用）
- VTT（Web 标准）
- ASS/SSA（样式丰富）

## 快速开始

1. **安装** — 下载适合你平台的版本
2. **导入** — 添加视频/音频文件到媒体库
3. **加载字幕** — 自动识别或在线搜索
4. **学习** — 点击、循环、遮罩，逐句掌握

## 技术亮点

- **毫秒级精度**：跳转响应 < 250ms，循环边界 ± 40ms
- **原生播放内核**：mpv（桌面）、AVPlayer（iOS）、ExoPlayer（Android）
- **跨平台 UI**：React / React Native 共享组件
- **本地优先**：SQLite 存储，无需网络
