# Audixa：全平台字幕驱动型音视频学习系统

## 一、产品定位（一句话）
Audixa 是一款 **以「字幕句子」为第一公民的全平台音视频学习播放器**，通过对字幕进行句子级控制（点击跳转、AB 循环、遮罩、统计），将“看/听内容”转化为“可量化的语言学习行为”。

---

## 二、核心技术理念

> **用原生播放器掌控时间与声音，用跨平台 UI 掌控字幕与学习。**

- 播放内核：稳定、精准、平台原生
- 字幕系统：完全自研、学习驱动
- UI / 交互：跨平台高度复用
- 架构目标：可扩展、可插件化、可长期演进

## 四、平台实现策略

### 1️⃣ 移动端（iOS / Android）

- 框架：**React Native（Bare 模式）**
- UI / 字幕 / 学习逻辑：RN
- 播放器：原生（AVPlayer / ExoPlayer）
- 通信：JSI / TurboModules

优势：
- 高度复用 UI 与业务逻辑
- 播放体验原生级
- 可支持动态学习功能演进

---

### 2️⃣ 桌面端（Windows / macOS）

- UI：React（与 RN 组件高度共享）
- 桌面壳：**Tauri（优先） / Electron（备选）**
- 播放内核：mpv（FFmpeg）

优势：
- 体积小、性能强
- 原生级播放控制
- 易于接入 NAS / 本地文件系统

---

### 3️⃣ 数据与同步（阶段性）

- 本地优先：SQLite / IndexedDB
- 云同步（可选）：
  - 学习记录
  - 收藏句子
  - 生词本

---

## 五、字幕系统：Audixa 的技术护城河

### 字幕不是展示，而是「学习数据模型」

```ts
SubtitleSentence {
  id
  startMs
  endMs
  textEn
  textCn
  playCount
  loopCount
  masteredLevel
}
```

字幕驱动能力：
- 点击字幕 = 精准 seek
- AB Loop = 天然句子边界
- 学习统计 = 可量化行为
