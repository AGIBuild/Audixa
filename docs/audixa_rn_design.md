# Audixa 跨平台应用开发技术方案

## 推荐方案 A：Monorepo + RN Bare + 模块化设计

> 适用场景：大型内容类应用，需整合原生能力（播放器、字幕、动画）及多端统一开发。

### 核心理念
- **Shared UI**：统一跨平台界面组件，确保视觉一致性并支持主题切换（紫洋红风格）
- **Shared State**：跨模块、跨页面状态统一管理，支持复读机功能的高频状态更新
- **Native Modules**：自由接入原生能力，如高性能播放器、字幕引擎、文件系统和网络缓存

### 技术栈与构成（现代推荐版）

#### 1. React Native (Bare)
- 最新版本（0.72+），支持 Hermes 引擎、Fabric 和 TurboModules
- 不依赖 Expo 管理层，减少打包冗余
- 支持自定义原生模块，接入复杂原生能力（视频解码、硬件加速、背景播放）
- 可灵活集成第三方 SDK（NAS 访问、网盘资源解析、在线字幕加载）

#### 2. Monorepo 工程化管理
- 工具推荐：**Turborepo V2** 或 **Nx 最新版**
- 结构示例：
  ```
  /packages
    /core       # 核心层 (播放器, 字幕引擎, 音频处理, 缓存管理)
    /ui         # UI 组件库 (按钮, 播放器控件, 字幕样式, 动画组件)
    /modules    # 业务模块 (字幕页, 学习中心, 复读机, 资源浏览)
    /utils      # Shared Utils / Types / API 封装
    /config     # 项目配置, 环境变量管理, i18n
  ```
- 支持代码复用、增量构建和快速迭代
- 每个模块可独立发布或热更新

#### 3. 状态管理
- **Zustand**：轻量、高性能，适合高频状态更新（播放进度、字幕滚动）
- **Redux Toolkit**：官方推荐 Redux 写法，适合复杂业务逻辑（学习中心课程管理、用户进度同步）
- 状态分层：
  - Core State：播放器、字幕引擎状态
  - Module State：业务模块专用状态
  - Shared State：用户登录、配置、主题、语言等全局状态

#### 4. 导航
- **React Navigation v6 + Native Stack**：现代、高性能导航方案
- 支持复杂页面跳转及模块嵌套
- 动态路由生成，按模块加载页面
- 支持深度链接和通知跳转

#### 5. 动画与手势
- **Reanimated 2 + Gesture Handler 最新版**
- 支持高性能交互动画（滑动字幕、拖拽复读区域）
- 自定义手势组合：单指滑动、双指缩放、长按拖拽
- 动画封装统一 API，便于跨模块复用

### 模块化设计思路
- **核心层**：播放器引擎（支持本地/NAS/网盘资源）、字幕渲染引擎（HTML/ASS/JSON 字幕格式）、音频处理、缓存管理
- **UI 层**：可复用组件库，支持主题与多语言，内置动画组件
- **业务模块**：
  - 学习中心：课程浏览、进度记录、笔记功能
  - 复读机页：精听、AB 循环、字幕交互
  - 字幕交互页：点击单词、段落高亮、实时翻译
- **共享工具**：类型定义、工具函数、API 封装、配置管理、i18n 多语言
- **原生模块扩展**：播放器控制、文件访问权限、硬件加速、推送通知

### 开发与迭代策略
- 每个模块独立开发、独立测试
- Monorepo CI/CD 流程：
  - Core 模块优先测试
  - UI 更新自动触发模块测试
  - 支持热更新发布和版本管理
