# Audixa - 字幕驱动的语言学习播放器

> 把任何视频变成你的语言学习课堂

## 产品简介

Audixa 是一款创新的音视频学习播放器，以**字幕句子**为核心，让你通过观看电影、美剧、纪录片等内容，高效提升语言能力。

不同于普通播放器，Audixa 将每一句字幕都变成可交互、可追踪的学习单元。点击即跳转、循环即复读、遮罩即听写——让「看内容」变成「真正的学习」。

## 为什么选择 Audixa

### 🎯 以句子为单位的精准控制

传统播放器只能按时间拖动，Audixa 让你以**句子**为单位控制播放：
- 点击任意字幕，立即跳转到对应位置
- 一键循环当前句子，反复精听
- 智能识别句子边界，告别手动找时间点

### 📚 你的私人听力素材库

遇到精彩的句子？一键保存到精听库：
- 自动记录音频片段和字幕
- 随时回放复习，无需重新定位
- 按需整理，打造个人学习资料

### 📖 即点即查的生词本

看到不认识的单词？点击就能查：
- 即时显示释义和发音
- 一键添加到生词本
- 积累属于你的词汇库

### 📊 可量化的学习进度

你的每一次学习都被记录：
- 句子播放/循环次数统计
- 学习时长追踪
- 掌握程度可视化

### 🌐 全平台无缝体验

无论你使用什么设备：
- **桌面端**：Windows、macOS
- **移动端**：iOS、Android（即将推出）
- 学习数据本地优先，隐私安全
