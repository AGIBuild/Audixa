# 快速开始

> 5 分钟上手 Audixa，开启高效语言学习

本指南将帮助你快速了解 Audixa 的基本使用流程，让你立刻开始学习。

## 安装 Audixa

### 下载

访问 Audixa 官网下载适合你系统的版本：
- Windows：下载 `.exe` 安装包
- macOS：下载 `.dmg` 镜像

### 安装

**Windows**
1. 双击安装包
2. 按向导完成安装
3. 从开始菜单启动

**macOS**
1. 打开 .dmg 文件
2. 拖动 Audixa 到 Applications 文件夹
3. 从启动台打开

## 添加你的第一个视频

### 步骤 1：导入媒体

1. 打开 Audixa，进入「媒体库」页面
2. 点击「添加媒体」按钮
3. 选择本地视频或音频文件
4. 文件出现在媒体库列表中

支持的格式：MP4, MKV, AVI, MP3, FLAC 等常见格式

### 步骤 2：加载字幕

如果视频已有内嵌字幕，Audixa 会自动识别。

如果需要外挂字幕：
1. 点击视频旁的「字幕」按钮
2. 选择「添加外挂字幕」
3. 选择字幕文件（SRT, VTT, ASS）
4. 字幕关联成功

没有字幕文件？使用在线搜索：
1. 点击「在线搜索字幕」
2. 系统自动匹配视频
3. 选择合适的字幕下载

## 开始你的第一次学习

### 播放与控制

1. 点击视频开始播放
2. 字幕显示在视频下方
3. 字幕列表显示在侧边栏

### 句子级跳转

- **点击字幕列表中的任意句子**
- 播放器立即跳转到对应位置
- 从该句开始播放

### AB 循环复读

1. 播放到想要循环的句子
2. 按下 `L` 键或点击「循环」按钮
3. 当前句子开始循环播放
4. 再次按 `L` 关闭循环

### 字幕遮罩

1. 按下 `M` 键或点击「遮罩」按钮
2. 字幕文字被遮盖
3. 尝试只用听力理解
4. 再次按 `M` 显示字幕

## 保存精彩内容

### 保存句子到精听库

遇到想要反复学习的句子：
1. 确保该句子正在高亮
2. 点击句子旁的「收藏」图标
3. 或按快捷键 `S`
4. 句子保存到精听库

### 查询并保存生词

遇到不认识的单词：
1. 点击字幕中的单词
2. 查看弹出的释义面板
3. 点击「添加到生词本」
4. 单词保存成功

## 复习你的收藏

### 精听库

1. 点击导航中的「精听库」
2. 浏览已保存的句子
3. 点击任意句子播放
4. 循环精听直到掌握

### 生词本

1. 点击导航中的「生词本」
2. 浏览已保存的单词
3. 点击查看详细释义
4. 定期复习巩固记忆

## 常用快捷键

掌握这些快捷键，学习效率翻倍：

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放/暂停 |
| `←` | 上一句 |
| `→` | 下一句 |
| `L` | 循环当前句 |
| `M` | 遮罩/显示字幕 |
| `S` | 保存当前句 |
| `↑` / `↓` | 调节音量 |
| `[` / `]` | 调节播放速度 |

## 推荐学习流程

### 初次学习

1. **通看**：先完整看一遍，了解大意
2. **精听**：回放重点段落，循环复读
3. **记录**：保存精彩句子，记录生词
4. **复习**：定期回顾精听库和生词本

### 日常练习

1. 打开一个学习素材
2. 设定今日学习时长（如 30 分钟）
3. 专注精听，遇到难点循环
4. 保存 3-5 个有价值的句子
5. 积累遇到的生词
6. 结束前查看学习统计

## 进阶技巧

### 选择合适的内容

- **入门**：语速慢、发音清晰的内容（如 TED 演讲）
- **进阶**：日常对话类（如美剧生活剧）
- **挑战**：语速快、口音多样（如英剧、访谈）

### 设定合理目标

- 每日学习时间：建议 30-60 分钟
- 新词积累：每日 5-10 个
- 精听句子：每日 10-20 句

### 保持规律

- 固定学习时间
- 每日打卡
- 追踪学习统计
