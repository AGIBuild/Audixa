# 全平台支持

> 无论你用什么设备，Audixa 都能陪伴你学习

Audixa 采用跨平台架构设计，为不同设备提供一致的学习体验。

## 支持平台

### 桌面端

#### Windows

- **系统要求**：Windows 10 或更高版本
- **架构**：x64
- **安装方式**：安装包 (.exe)

适合场景：
- 在电脑前系统学习
- 大屏幕观看学习内容
- 配合键盘快捷操作

#### macOS

- **系统要求**：macOS 11 (Big Sur) 或更高版本
- **架构**：Intel / Apple Silicon
- **安装方式**：应用包 (.app)

适合场景：
- Mac 用户日常学习
- 利用 Mac 优质音视频体验
- 与其他 Apple 设备协作

### 移动端（即将推出）

#### iOS

- **系统要求**：iOS 14 或更高版本
- **设备**：iPhone, iPad

适合场景：
- 通勤路上听力练习
- 碎片时间学习
- 配合 AirPods 使用

#### Android

- **系统要求**：Android 8.0 或更高版本
- **架构**：arm64, x86_64

适合场景：
- Android 手机/平板学习
- 随时随地练习听力
- 便携式学习体验

## 技术架构

### 统一的用户体验

无论你使用哪个平台，Audixa 都提供：
- **一致的界面设计**：相同的视觉语言和交互逻辑
- **相同的核心功能**：字幕控制、精听库、生词本等
- **统一的数据格式**：未来支持跨设备同步

### 原生性能

虽然界面跨平台，但播放能力使用原生技术：

| 平台 | 播放内核 |
|------|----------|
| Windows | mpv (FFmpeg) |
| macOS | mpv (FFmpeg) |
| iOS | AVPlayer |
| Android | ExoPlayer |

确保：
- 流畅的视频播放
- 精准的时间控制
- 低延迟的交互响应
- 硬件加速解码

### 本地优先

所有平台都遵循本地优先原则：
- 学习数据存储在设备本地
- 无需网络即可使用核心功能
- 隐私数据不离开设备

## 平台特性

### 桌面端特有

- **键盘快捷键**：高效的快捷操作
- **大屏幕布局**：更多信息同时展示
- **本地文件访问**：直接访问硬盘文件
- **NAS 支持**：WebDAV 协议访问

### 移动端特有（规划中）

- **触控优化**：适合手指操作的界面
- **后台播放**：锁屏后继续播放
- **系统集成**：通知中心控制
- **便携性**：随时随地学习

## 数据同步（规划中）

未来将支持跨设备数据同步：

### 同步内容

- 精听库收藏
- 生词本
- 学习统计
- 播放进度

### 同步方式

- 需要用户主动开启
- 端到端加密
- 增量同步，节省流量

### 冲突处理

- 最后修改优先
- 保留历史版本
- 可手动解决冲突

## 安装指南

### Windows

1. 下载 `.exe` 安装包
2. 双击运行安装程序
3. 按提示完成安装
4. 从开始菜单启动

### macOS

1. 下载 `.dmg` 镜像文件
2. 打开镜像，拖动应用到 Applications
3. 从启动台打开应用
4. 首次运行需要在系统偏好设置中允许

### 移动端（即将推出）

- iOS：App Store 下载
- Android：Google Play / APK 安装
