# 学习统计

> 量化你的学习行为，让进步可见

学习统计功能将你的每一次学习行为转化为可视化的数据，帮助你了解学习状态、保持学习动力。

## 功能特色

### 句子级学习追踪

**每个句子的学习深度都被记录**

系统自动追踪每个字幕句子的：
- 播放次数
- 循环次数
- 首次播放时间
- 最后播放时间

数据驱动的学习：
- 知道哪些句子听得最多
- 发现学习的重点和难点
- 追踪句子的掌握程度

### 学习时长统计

**投入的时间，清晰可见**

记录你的学习时间：
- 每日学习时长
- 累计学习时长
- 学习时段分布

建立学习习惯：
- 设定每日目标
- 追踪连续学习天数
- 发现最佳学习时段

### 内容覆盖分析

**了解你的学习广度**

统计学习内容覆盖：
- 播放过的媒体数量
- 学习过的句子总数
- 保存的精听句子数
- 积累的生词数量

### 进度可视化

**数据图表，一目了然**

直观的数据展示：
- 学习时长趋势图
- 每日活跃度日历
- 词汇增长曲线
- 内容完成进度

## 统计维度

### 时间维度

| 指标 | 说明 |
|------|------|
| 今日学习 | 当日累计学习时长 |
| 本周学习 | 最近7天总时长 |
| 本月学习 | 当月累计时长 |
| 总学习时长 | 历史总计时长 |

### 内容维度

| 指标 | 说明 |
|------|------|
| 播放媒体数 | 学习过的视频/音频数量 |
| 学习句子数 | 播放过的字幕句子总数 |
| 循环次数 | AB循环的总次数 |
| 精听保存数 | 精听库中的条目数 |
| 生词积累数 | 生词本中的词汇数 |

### 行为维度

| 指标 | 说明 |
|------|------|
| 句子跳转次数 | 点击字幕跳转的次数 |
| 查词次数 | 点击单词查询的次数 |
| 遮罩使用次数 | 使用字幕遮罩的次数 |

## 使用场景

### 场景一：学习习惯养成

利用统计数据建立习惯：
- 设定每日30分钟目标
- 查看连续打卡天数
- 追踪学习时段规律

用数据驱动习惯养成。

### 场景二：学习效果评估

量化学习投入和产出：
- 本周学习了多少小时？
- 积累了多少新词？
- 精听了多少句子？

定期复盘，调整策略。

### 场景三：难点发现

通过数据发现学习难点：
- 哪些句子循环最多？
- 哪些内容反复回看？
- 哪类生词积累最多？

针对性强化弱项。

### 场景四：进度激励

可视化进步过程：
- 看到词汇量稳步增长
- 观察学习时长累积
- 回顾已完成的内容

用成就感保持动力。

## 数据隐私

### 本地存储

所有学习数据默认存储在本地：
- 不上传到任何服务器
- 完全掌控自己的数据
- 隐私得到充分保护

### 可选云同步（规划中）

未来将提供可选的云同步功能：
- 需要用户明确开启
- 支持多设备数据同步
- 加密传输和存储

## 操作指南

### 查看统计

1. 打开「学习统计」页面
2. 查看总览面板的核心指标
3. 切换时间范围查看趋势
4. 点击详情查看更多维度

### 数据解读

**学习时长**
- 关注趋势而非绝对值
- 保持稳定比偶尔突击更有效

**句子循环**
- 高循环次数表示学习深度
- 但也可能提示该内容较难

**词汇增长**
- 稳定的新增表示持续学习
- 突然增加可能是新领域内容

## 最佳实践

### 设定合理目标

- 从可持续的小目标开始
- 逐步增加学习时长
- 质量比数量更重要

### 定期复盘

建议复盘频率：
- 每日：快速浏览今日数据
- 每周：总结本周学习情况
- 每月：评估整体进度和效果

### 关注关键指标

不必追踪所有数据，关注对你最有意义的指标：
- 如果目标是养成习惯 → 关注学习天数
- 如果目标是提升听力 → 关注精听句子数
- 如果目标是扩大词汇 → 关注生词积累
