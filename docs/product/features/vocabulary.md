# 生词本

> 点词即查，积累个人词汇库

生词本功能让你在观看视频时即时查词，并将生词保存下来系统复习。

## 功能特色

### 点词查询

**看到不认识的词？点一下就能查**

在字幕中遇到生词时：
- 直接点击字幕中的单词
- 弹出查词面板，显示释义和发音
- 无需切换应用，学习不中断

查词面板包含：
- 单词音标
- 词性标注
- 中文释义
- 发音播放

### 一键添加生词

**值得记住的词，一键保存**

在查词面板中：
- 点击「添加到生词本」
- 单词自动保存，包含上下文
- 下次遇到时快速回忆

### 生词本管理

**系统管理你的词汇积累**

- 按添加时间排序
- 支持搜索查找
- 去重机制，避免重复
- 记录学习状态

### 语境关联

**不只是单词，还有语境**

每个生词条目关联：
- 添加时的原句
- 所属媒体来源
- 添加时间戳

复习时可回溯原始语境，加深理解。

## 使用场景

### 场景一：美剧俚语积累

看美剧时遇到地道俚语：
- `gonna`、`wanna` 等口语缩写
- `hang out`、`figure out` 等短语动词
- 文化背景相关的表达

积累原汁原味的口语表达。

### 场景二：专业术语收集

观看纪录片或专业内容时：
- 科技领域专有名词
- 商业财经术语
- 学术表达方式

建立领域词汇库。

### 场景三：高频词强化

系统积累常见但未掌握的词：
- 阅读能认识但听不出的词
- 见过多次但仍不确定的词
- 容易混淆的近义词

从被动词汇转化为主动词汇。

## 技术实现

### 智能分词

系统自动将字幕文本分割为可点击的词语单元：
- 英文按词边界分割
- 支持常见短语识别
- 标点符号智能处理

### 词汇去重

采用规范化处理避免重复：
- 大小写统一
- 词形归一化（如 running → run）
- 相同语言/地区范围内去重

重复添加时更新「最后查看时间」而非创建新条目。

### 本地存储

生词本数据本地优先：
- 即时保存，无需网络
- 数据安全，隐私保护
- 支持未来云同步（规划中）

### 词条字段

每个生词条目包含：

| 字段 | 说明 |
|------|------|
| id | 唯一标识符 |
| word | 单词原形 |
| language | 语言标识 |
| createdAt | 首次添加时间 |
| lastSeenAt | 最后查看时间 |

## 操作指南

### 查询单词

1. 播放视频，显示字幕
2. 点击字幕中想查询的单词
3. 查看弹出的释义面板
4. 点击发音按钮听读音

### 添加生词

1. 查询单词后
2. 点击面板中的「添加到生词本」
3. 单词出现在生词本列表

### 浏览生词本

1. 打开「生词本」页面
2. 浏览已保存的单词列表
3. 点击任意单词查看详情
4. 使用搜索快速定位

### 管理生词

- **搜索**：输入单词快速查找
- **排序**：按添加时间或字母顺序
- **删除**：移除已掌握的单词

## 学习建议

### 即时记录

- 遇到生词立即查询和保存
- 不要等"之后再查"
- 利用语境帮助记忆

### 定期复习

建议复习节奏：
- 当天：快速浏览新添加的词
- 次日：回顾昨天的生词
- 每周：复习本周所有生词

### 主动使用

- 尝试用生词造句
- 在其他阅读/听力中留意
- 从被动记忆转为主动运用

### 适时清理

- 标记已掌握的单词
- 定期删除完全掌握的词
- 保持生词本精简有效
