# 字幕精听控制

> 让字幕成为你的学习指挥棒

字幕精听控制是 Audixa 的核心功能，将传统的"被动看字幕"转变为"主动用字幕学习"。

## 功能特色

### 句子级跳转

**点哪听哪，精准定位**

- 点击字幕列表中的任意句子，播放器立即跳转到对应位置
- 无需拖动进度条猜测时间点
- 毫秒级精准定位，不错过任何细节

使用场景：
- 某句话没听清？点击重听
- 想回顾刚才精彩的台词？一点即达
- 对照字幕逐句学习，效率翻倍

### AB 循环复读

**句子边界自动识别，循环复读更智能**

- 一键开启当前句子的循环播放
- 系统自动识别句子边界，无需手动设置起止点
- 支持调整循环范围，覆盖多个句子

使用场景：
- 难句精听：反复听直到完全理解
- 跟读练习：循环播放，模仿发音
- 听写训练：循环听写，检验理解

### 字幕遮罩/模糊

**遮住字幕，考验真实听力**

- 一键遮罩字幕文字，挑战纯听力理解
- 支持模糊效果，保留视觉线索
- 点击揭示答案，即时反馈

使用场景：
- 听力自测：先听后看，检验理解
- 听写练习：遮罩+循环，边听边写
- 渐进式学习：从模糊到清晰

### 双语字幕

**原文译文并行显示**

- 同时显示原文和译文字幕
- 灵活切换显示模式：仅原文/仅译文/双语
- 字幕偏移调整，解决时间不同步问题

## 技术亮点

### 毫秒级精度

Audixa 使用原生播放内核，确保：
- 跳转响应时间 < 250ms
- 循环边界误差 < 40ms
- 字幕同步误差 < 80ms

### 多格式支持

支持主流字幕格式：
- SRT（最常用）
- VTT（Web 标准）
- ASS/SSA（样式丰富）

### 在线字幕加载

没有字幕文件？Audixa 支持：
- 在线字幕搜索和下载
- 智能匹配媒体文件
- 一键加载，无需手动配置

## 操作指南

### 基础操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 跳转到句子 | 点击字幕 | 立即跳转播放 |
| 循环当前句 | `L` | 开启/关闭循环 |
| 上一句 | `←` | 跳转到上一句 |
| 下一句 | `→` | 跳转到下一句 |
| 遮罩切换 | `M` | 显示/隐藏字幕 |

### 进阶技巧

1. **多句循环**：按住 Shift 选择多个句子，设置循环范围
2. **倍速播放**：配合 0.75x 慢速，听清每个细节
3. **字幕偏移**：使用设置中的偏移调整，解决字幕不同步
