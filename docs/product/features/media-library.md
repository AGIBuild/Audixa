# 媒体库管理

> 一站管理你的所有学习素材

Audixa 支持多种媒体来源，让你轻松管理和播放各类学习素材。

## 支持的媒体源

### 本地文件

**直接播放电脑中的视频和音频**

- 支持导入单个文件或整个文件夹
- 自动识别常见视频/音频格式
- 文件引用方式，不占用额外存储空间

支持格式：
- 视频：MP4, MKV, AVI, MOV, WMV 等
- 音频：MP3, FLAC, AAC, WAV, OGG 等

### 本地文件夹监控

**指定文件夹，自动同步**

- 配置媒体文件夹路径
- 自动发现新增文件
- 文件删除后自动更新列表

适合场景：
- 下载目录自动入库
- 学习资料统一管理
- 多文件夹分类组织

### NAS / WebDAV

**访问家庭服务器上的媒体**

- 支持 WebDAV 协议
- 安全凭证存储（系统钥匙串）
- 远程目录浏览和播放

配置信息：
- 服务器地址
- 目录路径
- 用户名/密码

### 云盘（规划中）

**未来将支持主流云存储**

- 百度网盘
- 阿里云盘
- Google Drive
- OneDrive

## 媒体库类型

| 类型 | 说明 | 特点 |
|------|------|------|
| 手动库 | 手动添加文件 | 精确控制内容 |
| 文件夹库 | 监控指定目录 | 自动同步更新 |
| WebDAV 库 | 连接远程服务器 | NAS 用户首选 |
| 云盘库 | 连接云存储 | 随处访问（规划中） |

## 功能详情

### 多媒体库管理

- 创建多个独立的媒体库
- 按类型、用途分类组织
- 为每个库设置不同的源配置

示例组织方式：
```
📁 美剧学习
   └─ 本地文件夹: D:\Videos\US-Drama

📁 TED 演讲
   └─ WebDAV: nas.local/TED

📁 播客精选
   └─ 手动添加: 精选播客文件
```

### 播放历史

**自动记录观看进度**

- 记录每个媒体的播放位置
- 下次打开自动续播
- 最近播放列表快速访问

### 字幕关联

**媒体文件与字幕绑定**

- 自动发现同名字幕文件
- 支持手动关联外挂字幕
- 关联关系持久保存

### 媒体元信息

系统记录每个媒体项目的：
- 文件名和路径
- 来源类型
- 添加时间
- 最后播放时间
- 播放进度

## 操作指南

### 添加本地文件

1. 点击「添加媒体」按钮
2. 选择「导入本地文件」
3. 在文件选择器中选择文件
4. 文件出现在媒体库列表中

### 创建文件夹库

1. 点击「创建媒体库」
2. 选择类型「本地文件夹」
3. 配置文件夹路径
4. 保存后自动扫描内容

### 配置 WebDAV

1. 点击「创建媒体库」
2. 选择类型「WebDAV」
3. 填写服务器地址和目录
4. 输入用户名密码
5. 测试连接后保存
