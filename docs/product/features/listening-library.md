# 精听库

> 收藏精彩句子，打造个人听力素材库

精听库是 Audixa 的核心学习功能之一，让你可以保存任何精彩的句子片段，随时回放复习。

## 功能特色

### 一键保存当前句子

**遇到好句子？一键收藏**

当你在观看视频时，遇到想要反复学习的句子：
- 点击「保存句子」按钮
- 系统自动记录当前句子及其音频片段
- 句子立即出现在精听库中

保存的内容包括：
- 句子文本（原文 + 译文）
- 音频时间边界（起止时间点）
- 媒体来源引用
- 保存时间戳

### 独立播放复习

**脱离原视频，专注句子学习**

精听库中的每个句子都可以独立播放：
- 无需打开完整视频
- 精准播放保存的音频片段
- 支持循环播放模式

学习流程：
1. 打开精听库
2. 选择要复习的句子
3. 点击播放，专注精听
4. 循环播放直到掌握

### 批量管理

**高效整理你的收藏**

- 按保存时间排序
- 按媒体来源分组
- 支持搜索和筛选
- 批量删除不需要的条目

## 使用场景

### 场景一：电影经典台词

看电影时收集喜欢的台词：
- 发音优美的句子
- 地道的表达方式
- 有深意的对白

定期复习，模仿跟读，提升口语表达。

### 场景二：新闻听力素材

从新闻节目中提取：
- 播音员标准发音
- 时事热点词汇
- 正式场合表达

积累时事英语素材库。

### 场景三：播客精华片段

精选播客中的精彩内容：
- 嘉宾的观点陈述
- 专业领域术语
- 自然对话示例

打造主题学习素材。

### 场景四：难句攻克

专门收集听不懂的句子：
- 语速快的段落
- 连读弱读明显的句子
- 含有生词的句子

针对性训练，逐个攻破。

## 技术实现

### 精准时间边界

每个保存的句子都记录：
- `startMs`：起始时间（毫秒）
- `endMs`：结束时间（毫秒）

确保回放时精准复现原始片段。

### 媒体引用机制

精听库保存的是引用而非副本：
- 不重复存储音频数据
- 节省存储空间
- 依赖原始媒体可用性

注意：如果原始媒体文件移动或删除，相关精听条目将无法播放。

### 离线可用

精听库数据本地存储：
- 无需网络即可查看列表
- 本地媒体随时可播
- 支持未来数据导出

## 操作指南

### 保存句子

**方式一：播放器快捷操作**
- 播放过程中，当目标句子高亮时
- 点击字幕旁的「收藏」图标
- 或使用快捷键 `S`

**方式二：字幕列表操作**
- 在字幕列表中找到目标句子
- 右键菜单选择「保存到精听库」

### 播放精听库

1. 打开「精听库」页面
2. 浏览已保存的句子列表
3. 点击任意条目开始播放
4. 使用循环按钮反复精听

### 管理精听库

- **搜索**：在搜索框输入关键词
- **筛选**：按来源媒体筛选
- **删除**：选中条目后点击删除

## 最佳实践

### 适量保存

- 只保存真正需要复习的句子
- 避免"收藏即学完"心态
- 定期清理已掌握的条目

### 及时复习

- 保存后当天至少听一遍
- 使用间隔重复原则
- 搭配跟读/听写练习

### 分类整理

建议按用途分类收藏：
- 口语表达类
- 听力难点类
- 词汇积累类
- 语法示例类
